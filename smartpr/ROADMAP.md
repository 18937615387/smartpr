## 远期愿景 (2027 Q4+)

- **跨仓库协作**: 一个需求涉及多个微服务时，自动跨仓库协调
- **自然语言对话接口**: 通过对话式交互描述需求，系统实时生成并展示方案
- **自适应学习**: 系统从人工审查的修改中学习，逐步减少审查循环次数
- **安全合规扫描**: 自动检查生成的代码是否符合 OWASP、GDPR 等标准
- **多语言国际化**: 支持中文、日文等多语言需求描述

## 如何贡献

我们欢迎社区参与！以下是一些可以贡献的方向：

1. **Agent实现**: 帮助实现各Agent的核心逻辑
2. **适配器开发**: 为新LLM或项目管理工具编写适配器
3. **语言支持**: 为 Python / Go / Rust 等语言添加模板和最佳实践
4. **文档完善**: 改进文档、编写教程、录制演示视频
5. **测试**: 编写测试用例、报告Bug

请阅读 [CONTRIBUTING.md](CONTRIBUTING.md) 了解详细的贡献流程。
